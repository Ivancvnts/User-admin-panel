# User Management Dashboard

A small React application that simulates a user management dashboard. The app allows users to view a list of users, see detailed information for a selected user, and add new users through a form.

This project was built to practice core frontend development concepts, including React components, state management, props, form handling, and data rendering from local sources.

## Features

- Display a list of users
- View user details
- Add new users through a form
- Manage application state with React
- Responsive and clean user interface

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3

## Learning Goals

This project focuses on strengthening:

- React fundamentals
- State management with `useState`
- Component composition and props
- Form handling and validation
- Array methods such as `map`, `find`, and `filter`
- Building a complete frontend application from scratch
